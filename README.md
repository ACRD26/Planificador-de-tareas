Planificador de tareas

*Objetivo

Desarrollar una aplicación web utilizando HTML, CSS y JavaScript, poniendo en práctica los conocimientos adquiridos en desarrollo web y programación.


*Tecnologías utilizadas

HTML: estructura de la aplicación.

CSS: diseño y estilos visuales.

JavaScript: funcionalidades e interacción con el usuario.

Git y GitHub: control de versiones y almacenamiento del código.


*Funcionalidades

Agregar nuevas tareas.

Asignar fechas límite.

Establecer prioridades.

Editar y eliminar tareas.

Marcar tareas como completadas.

Filtrar tareas por estado.

Guardar las tareas en el navegador mediante localStorage.


*Estado del proyecto

En desarrollo.
